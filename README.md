# Vizsgaprojekt---PecsGo


PécsGo

Discover, plan, and organize experiences - all in one place!

About the Project:
PécsGo is a website designed to make finding, organizing, and sharing activities and experiences easier. Whether you're planning a family lunch, a weekend party, a relaxing walk, or a museum visit, PécsGo helps you discover activities that match your interests, preferences, and needs. Instead of searching through countless websites or losing important details in group chats, users can find everything they need in one convenient place.
Our goal is to make organizing free-time activities simple, enjoyable, and accessible to everyone, whether they prefer spending time alone, with friends, or with family.

Key Features:
PécsGo aims to provide the following features:

Activity Search & Discovery:
•	Browse available events and activities.
•	Filter results by category, price, distance, ratings, and date.
•	Discover personalized activity recommendations.
•	Access relevant and up-to-date event information.

User Accounts & Profiles:
•	User registration and login.
•	Personalized user profiles.
•	Profile pictures, usernames, and personal descriptions.
•	Individual preferences and search settings.
•	Password reset functionality.

Event Management:
•	Create and publish custom events.
•	Add event descriptions, dates, locations, and images.
•	Set events as public or private.
•	Save interesting activities to a personal collection.
•	Manage saved events and personal plans.

Friends & Groups:
•	Search for and add other users as friends.
•	Create groups with friends or family members.
•	Organize shared activities.
•	Communicate and coordinate plans within groups.

Reviews & Ratings:
•	Rate events and activities.
•	Write comments and share experiences.
•	Explore feedback from other users.

Moderation & Administration:
•	Moderator access and administrative interface.
•	Review user-submitted events before publication.
•	Manage and moderate uploaded content.
•	Help prevent harmful, misleading, or inappropriate content.
